Testnet guide

Ten minutes from nothing to a first look at an on-chain market.

  1. Open the wallet. Create a new wallet and write the recovery phrase on paper. Use a throwaway phrase here, never one you use anywhere else.
  2. Check it is on the testnet. The coloured "Testnet" tag in the top bar and the banner under it say so.
  3. Look at the oracle. It lists the latest committed prices and how many sources agreed on each.
  4. Look at the Dex. Orders on the book are outputs of the Dex contract; the explorer shows the same transactions.
  5. Open the Markets tab in the wallet to see prices next to the assets you hold.
Trading from the wallet itself is being added step by step. Today the wallet shows markets read-only; placing orders is done with the command-line scripts in the repository (see Instruments).

Getting test coins

There is no public faucet yet. The repository's testnet guide explains how to run the public test wallet and mine your own test coins.
