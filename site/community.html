Community

The network is only as alive as the people running it. These are the ways to take part, from five minutes to a standing commitment.

Run a node

Every node makes the network harder to stop. A small server is enough. Guide →

Mine

Mining secures the chain and earns block rewards. The node includes a miner; see the guide.

Vote

Use the wallet to vote on the community fund each interval. See the current stage →

Build

Write a contract, a wallet feature or a tool. Developers →

Test

Try the exchange, oracle and bridge on the testnet and report what breaks.

Report and discuss

Issues and proposals live on GitHub.

Principles

  • Everything is open source and reproducible from the repository.
  • Keys never leave your device; nothing here asks for your seed phrase.
  • Status is shown honestly: pages say when a service is syncing or unreachable instead of hiding it.
