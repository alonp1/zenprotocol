Protocol upgrades are decided by a vote of coin holders. Each vote names a commit id: the exact version of the code in the source repository. A holder votes by sending a transaction to the Repo voting contract with that commit id as its command. Every semester has two phases of 1,000 blocks each: first the Contestants phase, where a commit must gather more than the threshold (3% of all ZP at the Snapshot block) to become a contestant, then the Candidates phase, which picks the winner. The weight of a vote is the ZP balance of the voting wallet at the phase's Snapshot block, and only the first vote of a wallet in a phase is counted. The Repo contract has been inactive since block 233,874.
