About

Zen Chain is an independent, community-run continuation of the Zen Protocol blockchain. There is no company behind it: the software is open source and the infrastructure is run by volunteers.

Where it comes from

The Zen Protocol launched with an unusual design: smart contracts written in a language that lets the compiler prove properties of the code, and a built-in way for the community to steer a shared fund. The original team stepped back. The chain, its code and its community remained, and this project keeps them working: updated software that builds and runs today, a public node and seed, snapshots for fast sync, a block explorer, and a modern wallet.

What is new

  • Maintained node. The node builds with current tooling and runs in Docker on Linux, macOS and Windows.
  • Public infrastructure. Seed node, snapshots, explorer, asset list and governance history anyone can use.
  • Web wallet. Open source and non-custodial, with a read-only Markets tab.
  • Markets toolkit (testnet). An on-chain exchange, a price oracle that commits prices to the chain, and a prototype USDC bridge, all running on a test network first.
