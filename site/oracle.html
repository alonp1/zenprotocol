How it works

  1. Every hour the service reads each price from its data source.
  2. It hashes every ticker;value pair into a leaf and builds one Merkle tree.
  3. It sends the root to the Oracle contract (Commit), signed with the oracle key. The chain now proves the root existed at that block.
  4. Anyone asks the service for a value with its proof, and a contract or a person checks it against the root.

The oracle is trusted for the value itself. Everything after the commitment is verifiable. Read the design.
